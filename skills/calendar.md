# Calendar Skill

## Назначение
Управление событиями календаря macOS.

## Правила
- Не создавать событие без даты и времени.
- Относительные даты преобразовывать в конкретные даты.
- Перед изменением существующего события сначала найти его.
- Для удаления события сначала вызвать calendar.find_events по названию события.
- Из результата calendar.find_events взять UID нужного события и передать именно этот UID в calendar.delete_event. Никогда не передавать название события вместо UID.
- Не удалять события без подтверждения пользователя.
- Если календарь не указан, использовать календарь по умолчанию только если это однозначно.

## Tools
- calendar.find_events
- calendar.create_event
- calendar.delete_event

## Ограничения
Не использовать shell или произвольный AppleScript. Действовать только через зарегистрированные Tools.

## Примеры
Пользователь: «Поставь завтра в 9:30 бассейн на час».
Агент должен определить конкретные дату/время и вызвать calendar.create_event.
