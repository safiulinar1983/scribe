# Notes Skill

## Назначение
Работа с Apple Notes через явно зарегистрированные Tools.

## Правила
- Не удалять заметки без подтверждения.
- Не предоставлять LLM произвольный доступ к базе Notes.
- Импорт существующих Notes выполняется отдельным NotesImporter в read-only режиме.

## Tools
- notes.search
- notes.create
- notes.append
- notes.delete
